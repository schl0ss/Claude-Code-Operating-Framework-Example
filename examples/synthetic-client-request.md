# Synthetic Client Request

We want an AI assistant that watches our shared support inbox, creates tickets in our CRM, drafts replies, and escalates angry customers to a manager. Ideally it should just handle the easy ones automatically. Can you build that this week?

## Notes

This request is intentionally broad. A good framework should slow it down in the right places:

- Real customer email is confidential.
- CRM writes affect production records.
- Automatic replies create reputational risk.
- Escalation rules need business approval.
- "Easy ones" needs a definition before automation.

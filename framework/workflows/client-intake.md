# Workflow: Client Intake To Scoped Plan

## Purpose

Turn a messy client request into a scoped plan with risks, artifacts, and approval gates.

## Steps

1. Intake extracts goal, non-goals, constraints, unknowns, and risks.
2. Planner proposes the smallest useful milestone.
3. Safety agent identifies approval gates.
4. Critic challenges the plan against the request.
5. Delivery agent returns the plan, assumptions, and next decision.

## Done

- The next milestone is concrete.
- Unknowns are named.
- Risks are not hidden.
- Human approvals are explicit.
- The plan can be executed without private data.
